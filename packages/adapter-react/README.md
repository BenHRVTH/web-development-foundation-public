# @wdf/adapter-react — 0.1.0-rc.1

A Web Development Foundation közösen verziózott, helyi release candidate csomagja.
A source-workspace manifest fejlesztési TS-exportokat használ; az npm-artifact
fordított ESM JavaScriptet, TypeScript deklarációkat és pontos RC-függőségeket szállít.
A tényleges artifact manifestje az exports/types/bin/files szerződés mérvadója.

Dokumentáció: https://github.com/BenHRVTH/web-development-foundation-public/tree/main/docs

Nincs nyilvános npm-release. Node 24.22.1/npm 11.9.0 az ellenőrzött futtatókörnyezet.
A Lab és a QA fejlesztői eszköz; nem szükséges a kész webalkalmazás futtatásához.
Telepítés és korlátok: Getting Started, Developer Guide, Release Guide és M6-HANDOFF.
